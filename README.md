## 🌐 1-Minute Self-Hosting & Embed Guide for Webmasters

You have full permission to host or embed this tool on your personal, educational, or commercial website or blog!

### 1. Instant `<iframe>` Embedding (WordPress, Ghost, Medium, Hugo, Hexo)
Add this snippet directly into any page or article:

```html
<iframe src="https://www.useful-finds-daily.com/archive-reviewer-pro.html" 
        width="100%" height="720px" frameborder="0" allowfullscreen 
        style="border-radius: 12px; border: 1px solid #333; box-shadow: 0 4px 20px rgba(0,0,0,0.5);"></iframe>
<p style="font-size: 12px; text-align: center; color: #888; margin-top: 6px;">
  Free Tool Provided by <a href="https://www.useful-finds-daily.com/" target="_blank" rel="noopener" style="color: #4fc3f7; font-weight: bold; text-decoration: none;">Useful Finds Daily</a>
</p>
```

### 2. Standalone Hosting (Apache, Nginx, Shared Hosting, cPanel)
1. Download `index.html` from this repository.
2. Upload it to your web directory (e.g. `public_html/tools/archive-reader/index.html`).
3. Point your users to `https://yourdomain.com/tools/archive-reader/`.
4. Done! Requires zero database, zero PHP/NodeJS, and zero backend maintenance.

### 3. Deploy to GitHub Pages / Cloudflare Pages / Vercel in 30 Seconds
1. Fork or push this repository to GitHub.
2. In **Settings -> Pages**, select `main` branch `/ (root)` and click **Save**.
3. Your live tool is instantly published with free global CDN and HTTPS!

## ⚡ Key Highlights
- **100% Client-Side**: All decompression (WebAssembly unrar + JSZip) runs in the user's browser RAM.
- **Universal Format Support**: `.zip`, `.cbz`, `.cbr`, `.tar`, `.cbt`, `.7z`, `.rar`, `.cb7`.
- **Keyboard Navigation**: Flip through pictures using Left/Right arrow keys (`←` / `→`).
- **Touch Gestures**: Two-finger pinch-to-zoom (1x - 8x), smooth panning, and mobile swipe navigation.
- **Auto Multi-Language**: Auto-detects system language with support for 9 languages (EN, DE, ZH, ES, FR, IT, PT, RU, JA).
- **Duplicate Image Cleaner**: Built-in hash-based image deduplication and 1-click slimming.
